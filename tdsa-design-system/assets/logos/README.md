# Logos

Single-ink marks: `*-positive.png` is black, for light grounds; `*-white.png` is white, for dark grounds (night, dusk, dawn, or a photo under a night scrim). Long = horizontal lockup (header, footer, title slides); square = stacked lockup (avatars, social, tight spaces).

Never recolour, stretch, crop or add effects. Clear space: the height of the "A" in Arabia on every side. Minimum: long 120px wide, square 64px wide.

`tdsa-icon-positive.png` is the symbol alone (black): favicons, app icons, small marks, watermarks. There is no white version yet; on dark grounds use the white square lockup or ask for a white icon file — never invert or recolour this one.
