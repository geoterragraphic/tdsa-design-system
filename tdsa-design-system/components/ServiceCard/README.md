# ServiceCard

A photo-led card: real photography on top, an `h3` title in `ink-brand`, one or two lines of copy and a TextLink.

Used for Drone Services / Geospatial Services, industries, case studies ("Full Case Study") and insights ("Read More"). Cards sit on `surface` with a `line` border and `radius-md`, in a grid with `space-6` gaps on a `surface-alt` section. The consumer provides the photo.

The photo is `<img class="td-img">` (180px tall, cropped with `object-fit: cover`). The preview uses two concept images from the Concept group; production cards need real project photos.
