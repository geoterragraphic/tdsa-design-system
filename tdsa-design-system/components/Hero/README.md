# Hero

The opening section: a three-beat headline, one lead line, a primary and secondary CTA, and real drone or site photography.

- Headline in `display` (Avenir Black), `ink`, last beat in `ink-brand`. Three short beats, each on its own line.
- Lead in `ink-muted`; one sentence.
- CTAs: "Contact Us" (primary) and "Schedule Meeting" (secondary).
- Photography: a real drone or site photo as `<img class="td-img">` in a fixed-height frame (`object-fit: cover`). The preview uses `delivery-drone-flycart30-port.webp`; swap in a Saudi-site shot when one is available.
