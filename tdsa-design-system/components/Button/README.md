# Button

Short, verb-led actions in one primary style (Dusk fill, white label) and one secondary outline style.

- Primary: `.td-btn .td-btn-primary` — `action` fill, `on-action` label. One per view.
- Secondary: `.td-btn .td-btn-secondary` — outline in `ink-brand`.
- Labels from the site: "Contact Us", "Schedule Meeting", "View All …". Title Case, two to four words.
- Inside a dark band or footer, the primary uses FineDay fill with Night label (Dusk on Night has no visible edge).
- Focus: 3px FineDay ring. Radius `radius-md`, padding `space-3` × `space-6`, Avenir Medium 14px.
