# ProofStrip

A clean row of partner, client or certification logos on a light ground, under a small uppercase eyebrow.

Order on a page: technology partners → clients (Saudi Arabia, then Global Network) → certifications (GACA, GEOSA, ISO 9001 / 22301 / 45001, Vision 2030). The consumer provides the real logo files; the preview shows text tiles in their place. Keep logos single-colour and equal in optical size.
